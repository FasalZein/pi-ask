# pi-ask needs pi 0.99.0 or later

pi-ask raises its minimum pi version from 0.84.0 to 0.99.0. The floor gate (`pnpm run check:pi-floor`) tests 0.99.0, and the development dependencies follow pi 1.0.2. This decision supersedes the "0.84.0 and later" support line in issue #1.

pi 0.99.0 changed how tools reach the model: it added codemode, tool `exposure`, nested tool calls through `ctx.executeTool()`, and `isError` results. pi-ask now registers `ask_user` with `exposure: "model-only"`, because pi's extension docs recommend it for tools that ask the user. A codemode script must not open an interactive prompt that the model cannot see. Hosts before 0.99.0 do not know these fields, so a gate at 0.84.1 tested a tool model that no current host uses. It also forced runtime shims for `getNativeClipboard`, the mouse event type, and `buildSessionContext`.

`peerDependencies` stay `"*"`, as pi's package docs recommend for host-provided modules. Users on pi before 0.99.0 stay on pi-ask 1.0.1.
